# Kindle Dashboard

A collection of custom, dynamic lock-screen dashboards for jailbroken
Kindles — built with shell scripts and
[FBInk](https://github.com/NiLuJe/FBInk), no KOReader or KUAL
required. Each version lives in its own folder with its own setup
instructions.

## Versions

- **[halloween-cat-dashboard](halloween-cat-dashboard/)** — time,
  date, a year-progress bar, and Halloween-themed cat artwork,
  redrawn every time the device sleeps.

## Background reading (applies to every version)

- [FAQ_EXPLAINED.md](FAQ_EXPLAINED.md) — plain-language background on
  jailbreaking, what FBInk is, and why this kind of project is as
  fiddly as it is.
- [DEVICE_REFERENCE.md](DEVICE_REFERENCE.md) — confirmed specs and
  quirks for the Kindle this was built on (10th-gen basic / "Rex",
  hard-float). Re-run the calibration steps described there if
  targeting a different device.
